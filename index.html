Practice

Hit “New task” — the trainer picks a random key, mode and box and shows it on the fretboard right away.
Daily warm-up: one task = 3–4 minutes with the metronome. Slowly up and down first, then the given pattern. Five tasks in a row and you have warmed up the whole box system.
